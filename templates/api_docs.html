API Documentation

Interact with the BlueFlameSearch document repository programmatically via our RESTful JSON API. Great for testing via Postman or cURL.

GET

/api/docs

Retrieve a list of all documents stored in the database.

cURL: curl -X GET http://localhost:5000/api/docs
GET

/api/docs/<doc_id>

Retrieve details of a specific document by its ObjectId.

cURL: curl -X GET http://localhost:5000/api/docs/60a2b8...
POST

/api/docs

Create a new document. The search index will automatically rebuild.

cURL: curl -X POST http://localhost:5000/api/docs \
-H "Content-Type: application/json" \
-d '{"content": "Your text here"}'
PUT

/api/docs/<doc_id>

Update an existing document's content.

cURL: curl -X PUT http://localhost:5000/api/docs/60a2b8... \
-H "Content-Type: application/json" \
-d '{"content": "Your updated text here"}'
DELETE

/api/docs/<doc_id>

Delete a document permanently from the database.

cURL: curl -X DELETE http://localhost:5000/api/docs/60a2b8...
